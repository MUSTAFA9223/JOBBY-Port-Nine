# JOBBY MAPS — lightweight map testing

There are **zero maps currently installed**. The twelve heavyweight Twelve Arenas maps and the old viewer were removed from this branch to make room for testing a single lightweight mobile map at a time.

The 52 JOBBY character GLB files are **preserved** in `jobby-characters/` for future integration, but the landing page loads none of them.

The repository and its Git history remain. Maps in old commits may still be recoverable from history. JOBBY WORLD is a separate project and was not modified.
